# Kimlik Merkezi

Kişisel, çevrimdışı çalışan dijital kimlik ve veri merkezi. Veriler yerelde tek bir SQLite dosyasında durur; yapay zekâ uygulamaları yalnızca izin verilen kategorilerden, salt okunur erişir.

Durum: geliştirme aşamasında (v0.1.0 hazırlığı). Sözleşmeler: `docs/INTERFACES.md`.

Klasörler: `core/` çekirdek, `server/` persona ve erişim (MCP), `importers/` içe aktarıcılar, `windows/` kabuk ve kurulum, `android/` (v0.2.0), `entegrasyon/` uçtan uca testler, `spikes/` karar araştırmaları.
