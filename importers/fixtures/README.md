# Fixture'lar

Hepsi sentetik, uydurma içerik; gerçek kişisel veri yok.
- takeout_en: İngilizce Takeout yapısı (biçim bilgisi için durum/importers.md).
- takeout_tr: Türkçe klasör/dosya adları VARSAYIMDIR (gerçek Türkçe Takeout görülmedi); yalnız içerikle tanımayı sınar.
- takeout_eski_chrome: eski `BrowserHistory.json` adı. takeout_html: yalnız HTML (desteklenmez).
- reddit: hesap veri isteği CSV'leri (sütunlar doğrulanmadı).
